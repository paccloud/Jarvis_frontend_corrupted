# Technology Context

## Framework & Runtime
- **React**: Frontend framework for building user interfaces
- **JavaScript/JSX**: Primary programming language
- **Vite**: Modern build tool for faster development (to be implemented)

## Key Dependencies
- `react`: Core React library
- `react-dom`: React DOM rendering
- `lucide-react`: Icon library for UI components

## Browser APIs Used
- **Web Speech API**: 
  - `webkitSpeechRecognition`: Speech-to-text functionality
  - `speechSynthesis`: Text-to-speech functionality
- **DOM APIs**: Standard web APIs for UI interaction

## Architecture
- Single Page Application (SPA)
- Component-based architecture
- State management using React hooks (useState, useEffect, useRef)

## Features
- Voice recognition and transcription
- Text-to-speech synthesis  
- Multiple AI agent selection interface
- Chat-style message interface
- Real-time audio processing

## Development Setup Needed
- Package manager: npm/yarn/pnpm
- Build system: Vite recommended
- Development server for hot reloading
- Static file serving for production
